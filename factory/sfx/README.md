# The sound library

`library.py` keeps the factory's shared sound library: public-domain sounds (CC0 and the Public Domain Mark) found through Openverse, earshot's code-made bank, and sounds the sound writer makes in code. `factory/sfx_library/manifest.jsonl` is the licence ledger, one row per file.

This tool is made using Openverse (https://openverse.org) but is not endorsed or certified by Openverse, as the Openverse API terms of service require of applications that use the API. No video carries a sound credit: the library holds only sounds whose licence needs none (operator, 5 Nov).
